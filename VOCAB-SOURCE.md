# Vocabulary data attribution

`vocab-data.js` is adapted from [`cet_beyond_ks3000.json`](https://github.com/exam-data/CETVocabulary/blob/main/cet_beyond_ks3000.json) in [exam-data/CETVocabulary](https://github.com/exam-data/CETVocabulary). It retains entries without the source dataset's sixth-level marker, and stores the word, Chinese meaning, example, example translation, and frequency in a compact format.

The source project licenses its data under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This adapted vocabulary data is shared under the same license. The source project says some examples are generated; they are study examples, not authenticated CET-4 exam sentences. The site's original 40-word set is kept separately in `index.html`.
