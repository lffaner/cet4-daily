学习记录

学习记录保存在当前浏览器的本地存储中，不会自动跨设备同步。建议每周导出一次备份。

第一次使用 · 3分钟上手

  1. 用手机或电脑浏览器打开本站；学习记录保存在当前浏览器。
  2. 在「真题听力」或「真题阅读」选择试卷，点击「加载真题」。题目需要联网从第三方项目加载。
  3. 选择答案后点击「核对本组答案」。每题的作答结果和整组成绩会自动保存，答错的题自动进入「错题复测」。
  4. 在错题本先重听对应段落或重读原文，再选择答案、记录错因，提交后查看解析。复测按次日、答对后 3 天和 7 天安排；答错则次日重练。
  5. 每周到「学习记录」导出 JSON 备份；同一浏览器升级网站不会清空旧记录。
题目、答案、解析和音频链接来自第三方项目，不保证每份数据无误。没有可确认对应的音频或可读取的阅读原文时，本站会明确提示，不会补写内容。旧版只保存整组分数，无法还原旧错题。本站不是官方 CET-4 网站；学习记录不会自动跨设备同步。
